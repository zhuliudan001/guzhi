# 基金估值查询系统

一个自用的基金盘中估值与自选管理工具。Flask 后端统一抓取东方财富 / 天天基金的数据，前端是原生 HTML + CSS + JavaScript，没有构建步骤——改完刷新页面就生效。

## 功能

- **基金查询**：输入 6 位代码查询盘中估值与最新净值，自动保存最近 10 条搜索记录
- **自选管理**：拖拽排序、按涨跌幅排序、刷新单只或全部
- **持仓估算**：填写持仓金额后估算当日收益，顶部汇总持仓概览；可用「显示持仓」开关临时隐藏金额（不删除数据）
- **基金详情**：近 60 个交易日净值走势、阶段收益、资产配置、重仓股、关联板块、基金经理
- **数据备份**：导出 / 导入本地 JSON 备份，支持合并或覆盖，用于换设备或清理浏览器前留存数据
- **交易状态**：显示待开盘、交易中、午间休市、周末休市、节假日休市与下次开盘时间，交易中每 1 分钟、休市每 5 分钟自动刷新

## 估值语义

估值的来源和口径是这个项目最容易出错的地方，前后端都依赖下面这套约定：

| 展示标签 | `estimate_source` | 含义 |
|---|---|---|
| 盘中估值 | `official` | 天天基金批量估值接口给出的实时估值 |
| 测算参考 | `derived` | 后端按重仓股行情加权测算的参考值，仅供参考 |
| 最新净值 | `null` | 没有可用估值，回退展示最新披露净值 |

- **`gsz`** 始终是「当前参考净值」：有估值时是估算净值，没有估值时是最新净值。
- **`gszzl`** 只在有估值时作为估值展示。没有估值时，列表的估算涨幅列回退展示最新净值日涨跌，并打上「净值」标签、日涨跌列显示 `—`，避免同一个数字出现两次。
- **`jzzzl`** 是最新净值的日涨跌。
- **测算时效**：`derived` 只在「行情所属交易日晚于最新净值日期」时给出。休市日、节假日以及当日净值已公布时，盘面涨跌已经包含在最新净值里，再叠加一次就是重复计算——这些情况下必须回退为无估值，保持 `has_estimate: false`。时间戳是测算时刻，不代表官方估值时间。
- 没有估值的基金不展示伪造的收益：持仓收益显示 `--`，不会被当成 0。

颜色遵循 A 股习惯：**红涨绿跌**。

## 快速开始

### Windows 一键启动

双击 `启动服务.bat`。脚本会检查 Python 与依赖，启动 API（5000 端口），在 8090–8099 中挑一个可用端口起静态服务，然后打开浏览器。

### 手动启动

```bash
pip install -r requirements.txt

python fund_api.py                              # 后端 :5000
python -m http.server 8090 --bind 127.0.0.1     # 前端 http://localhost:8090
```

前端会自动解析 API 地址（本地用 `http://localhost:5000/api`；路径以 `/guzhi` 开头时用 `/guzhi/api`；其余同源 `/api`），不需要改代码。

## API

| 路径 | 方法 | 说明 | 上限 |
|---|---|---|---|
| `/api/fund/<code>` | GET | 基金基础数据（估值或最新净值） | — |
| `/api/fund/<code>/detail` | GET | 详情：重仓股、板块、走势、资产配置、经理 | — |
| `/api/funds/batch` | POST | 批量基础数据 | 20 只 |
| `/api/funds/fast` | POST | 批量快速估值 | 50 只 |
| `/api/trading-status` | GET | A 股交易状态与下次开盘时间 | — |
| `/api/health` | GET | 健康检查 | — |

所有接口同时支持 `/api/...` 与 `/guzhi/api/...` 两种前缀。错误映射：基金不存在 → 404，上游不可用 → 502，请求体超过 64KB → 413，未知异常 → 通用 500（不泄露内部细节）。

## 数据来源

| 数据 | 来源 |
|---|---|
| 盘中估值（批量） | `fundcomapi.tiantianfunds.com` |
| 历史净值 | `api.fund.eastmoney.com` |
| 基金搜索 | `fundsuggest.eastmoney.com`（只接受代码精确匹配且含基础信息的条目） |
| 详情数据 | `fund.eastmoney.com` / `fundf10` / `push2` |

上游请求全部由服务端发起，带重试与超时。缓存 TTL：元信息 6 小时、净值 5 分钟、估值 60 秒（失败缓存 15 秒）、详情 5 分钟。批量基础数据最多 5 线程，避免被上游限流。

前端不依赖任何 CDN；只有详情页的走势图在打开时按需加载 Chart.js，加载失败显示降级提示，不影响其他数据。

## 项目结构

```
fund_api.py          Flask 后端（所有上游请求、缓存、错误映射）
index.html           页面结构
style.css            样式
app.js               前端交互逻辑
app-utils.js         共享工具（UMD，供浏览器与 Node 测试共用）
tests/               Python unittest + Node 测试
gunicorn.conf.py     Gunicorn 配置（gthread 2 workers × 8 threads）
start.sh / stop.sh / restart.sh    生产启停脚本
启动服务.bat          Windows 一键启动
```

## 数据与隐私

- 自选基金、持仓金额、搜索记录、自动刷新设置、显示持仓偏好都保存在浏览器 localStorage，不上传服务器。
- 备份完全在浏览器本地读写，导出后由用户自行保管——备份文件包含持仓金额，请勿公开分享。
- 风控上限：最多 200 只自选、10 条搜索记录，备份文件最大 1MB；格式不符的记录会被忽略并在导入预览中计数提示。

## 注意事项

盘中估值是参考值，实际净值以基金公司公布为准。部分基金（QDII、货币基金等）没有盘中估值，系统会降级展示最新披露净值。
